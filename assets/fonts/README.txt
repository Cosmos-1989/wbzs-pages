Local typography assets for 物不知数

STIXGeneral*.woff2
Converted from the STIX TrueType fonts bundled with Matplotlib to WOFF2.
The four files provide regular, bold, italic and bold italic Latin text.
Font outlines are unmodified. License and notices: LICENSE_STIX.txt.
Source: https://github.com/matplotlib/matplotlib/tree/main/lib/matplotlib/mpl-data/fonts/ttf

WuzhiSongSC-Regular.woff2 / WuzhiSongSC-Bold.woff2
Derived from Noto Serif SC, fixed weights 400 and 700. Subset to GB2312,
current site characters and available punctuation; renamed Wuzhi Song SC.
Each contains 7553 encoded characters. These fonts are the local web
fallback for devices without a Chinese Song typeface; no CDN is used.
Source: https://github.com/google/fonts/tree/main/ofl/notoserifsc
License and copyright notice: OFL-NotoSerifSC.txt.
Regenerate with scripts/subset_fonts.py and the upstream variable TTF.
The upstream TTF is an authoring input, not a publication asset.

System Songti SC / STSong / SimSun are only referenced as locally installed
fonts. Proprietary system font files are not bundled or redistributed.
