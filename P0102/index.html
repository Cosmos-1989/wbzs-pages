P0102 · 出版物习题 · 原书第 1.67 题

两把相对运动的尺：分处两端的钟与往返信号

四只端点钟在两个不同相遇事件置零；由 B' 接收读数反推尺长，并求 B、A'、A 的接收读数。

35P洛伦兹变换同时性相对性固有时光信号事件
难度与预备知识

四只钟各自在不同相遇事件置零；须区分 B 与 B' 接收、A 与 A' 接收这四条世界线及其钟读数。

预备知识：洛伦兹变换、长度收缩、惯性系同步、光的世界线。

难度说明 ↗

1 题目

1.1 物理情境

两把固有长度相同的直尺 ABABAB 与 A′B′A\prime B\primeA′B′ 分别静止在惯性系 SSS 与 S′S\primeS′。S′S\primeS′ 相对 SSS 沿尺的 A→BA\to BA→B 方向以速度 vvv 运动，0<v<c0<v<c0<v<c。每个端点各固定一只随端点运动的钟。

1.2 物理过程

SSS 系的两只端点钟先彼此同步，S′S\primeS′ 系的两只端点钟也先彼此同步。AAA 与 A′A\primeA′ 相遇时将这两只钟同时置零，BBB 与 B′B\primeB′ 相遇时也将那两只钟同时置零。A,A′A,A\primeA,A′ 相遇瞬间，A′A\primeA′ 发出沿正向传播的光信号；已知 B′B\primeB′ 接收它时，B′B\primeB′ 钟恰读一个时间单位。B′B\primeB′ 随即向负向发出应答光信号。

1.3 已知参数和理想化假设

真空光速为 ccc，两尺无相互作用，钟为理想钟。记 β=v/c\beta=v/cβ=v/c、γ=(1−β2)−1/2\gamma=(1-\beta^2)^{-1/2}γ=(1−β2)−1/2。把已知的一个时间单位记为 T∗T_*T∗​；任何钟的读数都指该钟世界线上自其置零事件起的固有时。

1.4 求解目标

（1）原始光信号抵达固定端点 BBB 时，BBB 钟读数是多少？（2）B′B\primeB′ 发出的应答信号先后抵达 A′A\primeA′ 与 AAA 时，各自钟的读数是多少？结果均以 T∗T_*T∗​ 为单位表示。

2 思路与提示

先列出两次端点相遇在 SSS 和 S′S\primeS′ 中的时间差，再把光传播时间与“置零时间”相减或相加。不要把 BBB 与 B′B\primeB′ 的接收事件当成同一事件。

3 解答展开 / 收起

3.1 指定事件和两种同时性

设共同固有尺长为 LLL。在 SSS 中取 AAA 的位置 x=0x=0x=0，BBB 的位置 x=Lx=Lx=L，并令 A=A′A=A\primeA=A′ 的相遇及发光事件为 (t,x)=(0,0)(t,x)=(0,0)(t,x)=(0,0)。运动尺在 SSS 中的同时长度为 L/γL/\gammaL/γ，所以此刻 B′B\primeB′ 位于 x=L/γx=L/\gammax=L/γ。

B′B\primeB′ 再向右走到固定 BBB 所需的 SSS 系时间为

Δ=L−L/γv=Lc 1−γ−1β>0.\Delta=\frac{L-L/\gamma}{v}=\frac Lc\,\frac{1-\gamma^{-1}}{\beta}>0.Δ=vL−L/γ​=cL​β1−γ−1​>0.
（1）

因此在 SSS 中，B=B′B=B\primeB=B′ 的相遇与置零事件比 A=A′A=A\primeA=A′ 晚 Δ\DeltaΔ。用标准洛伦兹变换求同一相遇事件在 S′S\primeS′ 的时刻：

tBB′′=γ(Δ−vLc2)=−Δ.t^\prime_{BB^\prime}=\gamma\left(\Delta-\frac{vL}{c^2}\right)=-\Delta.tBB′′​=γ(Δ−c2vL​)=−Δ.
（2）

所以在 S′S\primeS′ 中，置零顺序相反：B=B′B=B\primeB=B′ 比 A=A′A=A\primeA=A′ 早 Δ\DeltaΔ。同一数值的时间差来自两把尺固有长度相同，并非两事件同时。

3.2 用 B' 的已知读数固定长度尺度

在 S′S\primeS′ 中 A′,B′A\prime,B\primeA′,B′ 静止，相距 LLL。初始光从 A′A\primeA′ 走到 B′B\primeB′ 历时 L/cL/cL/c，但 B′B\primeB′ 的钟已在 −Δ-\Delta−Δ 置零。因此接收时的钟读数不是 L/cL/cL/c，而是

T∗=Lc+Δ=Lc(1+1−γ−1β),Lc=T∗ββ+1−γ−1.T_*=\frac Lc+\Delta=\frac Lc\left(1+\frac{1-\gamma^{-1}}{\beta}\right),\qquad \frac Lc=T_*\frac{\beta}{\beta+1-\gamma^{-1}}.T∗​=cL​+Δ=cL​(1+β1−γ−1​),cL​=T∗​β+1−γ−1β​.
（3）

3.3 原始信号抵达 B 时的钟读数

在 SSS 中原始光由 x=0x=0x=0 传播到固定 x=Lx=Lx=L，接收事件发生在 t=L/ct=L/ct=L/c；BBB 钟则在 t=Δt=\Deltat=Δ 才置零。因此

tB=Lc−Δ=Lc(1−1−γ−1β).t_B=\frac Lc-\Delta=\frac Lc\left(1-\frac{1-\gamma^{-1}}{\beta}\right).tB​=cL​−Δ=cL​(1−β1−γ−1​).
（4）

代入第（3）式，用 γ−1=1−β2\gamma^{-1}=\sqrt{1-\beta^2}γ−1=1−β2​ 化简得

tB=T∗β−1+1−β2β+1−1−β2=T∗1−β1+β.t_B=T_*\frac{\beta-1+\sqrt{1-\beta^2}}{\beta+1-\sqrt{1-\beta^2}}=T_*\sqrt{\frac{1-\beta}{1+\beta}}.tB​=T∗​β+1−1−β2​β−1+1−β2​​=T∗​1+β1−β​​.
（5）

读数为正，说明 BBB 的置零发生在接收原始光之前。

3.4 应答信号抵达 A' 与 A

B′B\primeB′ 接收原始光后立刻沿负向发光。在 S′S\primeS′ 中，光从固定 B′B\primeB′ 返回固定 A′A\primeA′ 又需 L/cL/cL/c。A′A\primeA′ 从初始相遇时起读时，所以

tA′=2Lc=T∗(1+1−β1+β).t_{A\prime}=\frac{2L}{c}=T_*\left(1+\sqrt{\frac{1-\beta}{1+\beta}}\right).tA′​=c2L​=T∗​(1+1+β1−β​​).
（6）

求固定 AAA 的接收必须改回 SSS 系。原始光的位置是 x=ctx=ctx=ct，B′B\primeB′ 的位置是 x=L/γ+vtx=L/\gamma+vtx=L/γ+vt；二者相遇时

trec,B′=L/γc−v,xrec,B′=c trec,B′.t_{\mathrm{rec},B\prime}=\frac{L/\gamma}{c-v},\qquad x_{\mathrm{rec},B\prime}=c\,t_{\mathrm{rec},B\prime}.trec,B′​=c−vL/γ​,xrec,B′​=ctrec,B′​.
（7）

应答光从此位置以速度 −c-c−c 返回 x=0x=0x=0，再用同样长的 SSS 系时间。AAA 钟自 t=0t=0t=0 起读时，故

tA=2trec,B′=2Lcγ(1−β)=T∗(1+1+β1−β).t_A=2t_{\mathrm{rec},B\prime}=\frac{2L}{c\gamma(1-\beta)}=T_*\left(1+\sqrt{\frac{1+\beta}{1-\beta}}\right).tA​=2trec,B′​=cγ(1−β)2L​=T∗​(1+1−β1+β​​).
（8）

第（6）与（8）式对应两个不同接收事件，因而无需让两只钟的读数相等。

4 方法与讨论

此题的核心不是套用“运动的钟变慢”，而是建立事件表：两次置零相遇、原始光分别抵达 B,B′B,B\primeB,B′、应答光分别抵达 A,A′A,A\primeA,A′。先在各尺静止系处理自己的端点钟，再对需要跨系比较的接收事件用洛伦兹变换和光的世界线；这样每一步的时刻都对应明确事件。
