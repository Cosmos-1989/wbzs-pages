专题阅读路径

沿着一个明确问题阅读相关章节：先建立概念与假设，再证明结构性结论，最后进入例题、边界与应用。

周期、对称与有限频谱整除、剩余与插值有限数据、计数与递推仿射结构、二次型与圆锥曲线齐次坐标、交比与极线线性振动、边界与模态线性响应、滤波与空间频率能量、稳定与平衡涨落从猜想到证明

周期、对称与有限频谱

先区分周期存在与最小性，再研究运算、频谱及整数采样。

01从平移到结构

周期不是一个孤立的数，而是一组保持函数的平移；连续性决定这一组平移能否稠密。

  1. 周期函数与最小正周期区分一个周期与最小正周期，并从定义检查平移不变性。
  2. 周期集合与实数的加法子群把逐个寻找周期转化为研究全部允许平移的代数结构。
  3. 连续周期函数的最小正周期把连续性转化为周期集合的闭性，补全最小正周期存在性的证明。
  4. 公度周期、公共周期与最小公倍数区分输入函数的公共周期与运算结果可能更短的最小周期。

02研究运算的边界

分别处理恒定子和、零点与自然定义域，证明公度性何以必要。

  1. 两个连续周期函数之和的周期判据通过平移差分证明公度性的必要性，而不只验证一个候选周期。
  2. 有限个周期函数的和与子和消去说明多项叠加为何必须排除恒定子和，并给出完整的归纳论证。
  3. 连续周期函数的积与商：零点和定义域用非零集合的平移不变性处理对数方法遗漏的零点。
  4. 反周期、符号翻转与周期群的陪集将“平移后变号”作为独立的对称关系，解释平方与乘积的周期缩短。

03分离有效频率

先证明表示唯一，再抽取频率分量；由整数最大公因数计算最小周期。

  1. 有限指数族的线性无关与频谱唯一性由一个消去算子逐一恢复系数，证明不同频率不能暗中抵消。
  2. 拉格朗日插值与有限数据的唯一性从根数上界得到插值唯一性，用基函数构造答案，并解释次数约束不可省略。
  3. 微分算子的分量投影与多项式插值用作用于函数空间的插值多项式，抽取一个指定频率。
  4. 三角多项式与有限复指数和的最小周期从有效频谱得出充要条件，再用整数最大公因数确定最小性。
  5. 两个不同频率正弦之积的周期积化和差产生新频率，奇偶性决定公共周期是否减半。
  6. 两个不同频率正弦之商的周期先约束分母零点格，再检查平移后的符号一致性。

04比较连续与离散

求导、积分、采样改变了哪些结构？区分精确重复、平均漂移与近似回归。

  1. 周期函数的导数、原函数与平均值求导保持已知周期，积分是否保持周期则取决于一个周期的平均值。
  2. 离散序列的周期、混叠与单位根整数采样后先按模 2π 合并频率，再用单位根的阶求整数周期。
  3. 不可公度频率的近似回归用抽屉原理说明非周期信号为何仍可能在长时间后近似重现。

整除、剩余与插值

用相容性、存在性和唯一性，贯通整数与多项式的余数问题。

01整数中的公因数

从欧几里得算法到贝祖等式，再用素因数赋值刻画整除。

  1. 欧几里得算法与贝祖等式用带余除法与最小正线性组合刻画最大公因数，推导整除消去律与丢番图方程。
  2. 素因数分解与赋值从贝祖消去律证明算术基本定理，以素数指数计算最大公因数、最小公倍数与整除性。

02拼合局部余数

先解一次同余，再处理多组余数的相容性；解的唯一性要说明模数。

  1. 同余与一次同余方程同余类运算、逆元条件、非互素系数的正确约分和全部解类。
  2. 中国剩余定理与相容性同时证明互素模数构造、非互素模数相容条件和最小公倍数意义下的唯一性。

03多项式的同一结构

次数约束代替整数大小，插值把有限个点值拼成唯一的低次多项式。

  1. 多项式的带余除法与余式定理从首项消去证明带余除法的存在唯一性，说明余式、代入与重根条件的关系。
  2. 多项式同余与模多项式计算把带余除法组织为代数运算，证明逆元判据，并区分相同零点与重根信息。
  3. 拉格朗日插值与有限数据的唯一性从根数上界得到插值唯一性，用基函数构造答案，并解释次数约束不可省略。
  4. 微分算子的分量投影与多项式插值用作用于函数空间的插值多项式，抽取一个指定频率。

有限数据、计数与递推

把数值模式提升为可证明的恒等式，明确初值与次数条件。

01对象与系数

先说清楚在数什么，再解释为什么同一对象可以产生两种求和。

  1. 有限计数的分类、分步与等纤维原则把加法、乘法及除法原则统一为有限集合映射的计数，推导排列组合与星杠双射。
  2. 二项式定理与系数提取通过选取指标证明展开式，建立系数提取、帕斯卡递推及奇偶过滤。
  3. 双计数与组合恒等式先确定同一个有限对象集合，再用两种分类证明带权组合和与范德蒙德恒等式。

02从点值到差分

有限观察只有配合次数上界，才能确定整个多项式。

  1. 拉格朗日插值与有限数据的唯一性从根数上界得到插值唯一性，用基函数构造答案，并解释次数约束不可省略。
  2. 有限差分与牛顿插值展开差分降低多项式次数，以二项式多项式构造离散的泰勒展开与有限和。

03从对称到递推

和积坐标与根的幂和揭示数列背后的代数关系。

  1. 多项式的根与韦达定理根的重数、根数上界及根与系数的对应。
  2. 二元对称多项式与和积坐标证明二元对称多项式的表示与唯一性，说明交换对称、幂和递推和实数可实现区域。
  3. 牛顿恒等式与多元幂和连接多项式系数、基本对称量与根的幂和，推导低阶校正项和高阶递推。

04解的完备性与生成函数

从一个固定点到特征根，再把递推与初值一起编码。

  1. 一阶仿射递推与固定点固定点平移、一阶递推的完整分类及稳定性；二阶递推独立成篇。
  2. 二阶常系数递推与特征根用初值唯一性证明特征根通解，处理重根、零根退化与复根振荡。
  3. 普通生成函数与递推的代数化以形式幂级数编码数列，证明卷积乘法和可逆条件，逐项把递推化成有理式。
  4. 离散序列的周期、混叠与单位根整数采样后先按模 2π 合并频率，再用单位根的阶求整数周期。

仿射结构、二次型与圆锥曲线

把坐标计算中的不变量提炼出来，分清欧氏度量与仿射关系。

01坐标与仿射不变量

向量、重心和面积比提供不依赖特殊画法的语言。

  1. 欧氏向量、内积、投影与叉积连接代数向量运算与长度、角度和力矩。
  2. 仿射变换与平行、中点和面积比由可逆线性变换和平移说明哪些几何量保持，哪些度量量改变。
  3. 三角形的重心坐标与有向面积由唯一仿射表示推导面积坐标、内外点判别以及三角形内的线性插值。

02二次型的内部结构

极化抽出双线性关系；谱定理给出主轴，平移则消去一次项。

  1. 二次型的极化与双线性正交从平方和展开得到双线性型，并统一点差法、共轭方向及切线。
  2. 二维谱定理与二次曲线主轴证明实对称二阶矩阵能正交对角化，并把混合项消去落实为特征方向。
  3. 二次曲线的中心与一次项消去以线性方程区分唯一中心、中心直线和无中心，并严格推出配方公式。

03把结构用于弦与分类

从二次型正交推导中点、共轭直径和切线，检验实点存在条件。

  1. 直线与椭圆：交点、判别式和切线斜率汇总直线与椭圆联立后的根系数关系、交点数判据和外点切线斜率。
  2. 椭圆第三定义与弦中点的点差法用极化恒等式统一直径所对斜率积和弦中点轨迹。
  3. 椭圆的共轭直径与垂直直径由二次型正交推导共轭直径的长度、面积、线性组合和切圆半径，并与欧氏垂直直径比较。
  4. 一般二次曲线的矩阵分类与退化判据用二次型的秩、符号和齐次矩阵行列式判定椭圆、双曲线、抛物线及全部实退化情形。

齐次坐标、交比与极线

将有限点与无穷远点放在同一框架中，理解射影不变量与对偶。

01先扩充坐标语言

平行直线的交点需要齐次坐标；交比则能在坐标改变后保持。

  1. 齐次坐标、无穷远点与直线求交把平行线求交和坐标图失效统一为齐次线性代数。
  2. 射影直线的交比与分式线性变换用二阶行列式定义交比，证明其不变性，并处理无穷远与调和分点。

02从直线参数到曲线

把分式线性变换提升到圆锥曲线，并检查实参数化的条件。

  1. 圆锥曲线上的交比与射影变换说明圆锥曲线的参数、斜率与分式线性变换之间的精确对应。

03点与直线的对偶

以极化为基础推导极线，区分代数极线和真实切点。

  1. 二次型的极化与双线性正交从平方和展开得到双线性型，并统一点差法、共轭方向及切线。
  2. 二次曲线的切线、极线与对偶方程齐次矩阵同时给出曲线上切线、曲线外点的极线、切点弦及直线的相切判据。

线性振动、边界与模态

从有限个振子的质量内积，走向连续介质的本征问题。

01有限维模式

说明质量矩阵为何改变内积，以及简正坐标如何使运动方程解耦。

  1. 简谐运动、初始条件与相图从微分方程确定振幅和相位，避免反正切的象限歧义。
  2. 特征值与特征空间用不变的一维方向理解线性算子。
  3. 耦合振动、质量内积与简正模式从二次能量构造模态基底，并由初值求各模式的激发。

02从离散到连续

边界条件筛选允许频率，权内积与边界项保证正交。

  1. 弦的横波、波动方程与行波从微小弦段的动力学推导传播方程。
  2. 驻波：边界条件与本征频率从分离变量推导整数谱和半整数谱，并区分局部能流与平均能流。
  3. Sturm–Liouville 模态、权内积与边界条件从弦的非均匀密度得到权内积，证明正交性并检查边界项。

03重建运动与估计频率

正交不自动意味着完备；在明确的展开条件下处理初值，并用能量估计基频。

  1. 傅里叶模态展开与弦的初值问题逐项求系数与能量，说明完备性、收敛和有限截断的区别。
  2. Rayleigh 比值与固有频率的变分估计以模态展开证明最低频率上界，说明试探函数和边界条件的作用。
  3. 不可公度频率的近似回归用抽屉原理说明非周期信号为何仍可能在长时间后近似重现。

线性响应、滤波与空间频率

用单位源响应连接微分方程、电路和成像。

01初值与因果性

把初始储能与外力响应分开，理解时不变性为何导出卷积。

  1. RC 电路、初值与充放电能量从节点守恒求完整一阶响应，并核对电源功、储能和热。
  2. LC 振荡与 RLC 的三类阻尼由储能元件建立二阶方程，给出初值解和耗散判据。
  3. 拉普拉斯变换、初始储能与极点保留开关前初值，分清零输入与零状态响应并检验终值条件。
  4. 受迫振动、相位滞后与共振分开位移共振、速度共振和平均功率共振。
  5. 因果线性响应与卷积从脉冲叠加推导卷积，并区分初值、稳定性与稳态频谱。

02边值问题的响应

Green 函数的连续性、导数跳跃与边界条件必须同时满足。

  1. 驻波：边界条件与本征频率从分离变量推导整数谱和半整数谱，并区分局部能流与平均能流。
  2. Green 函数：边值问题的单位源响应用固定端受力弦推导导数跳跃、叠加公式和零模障碍。

03实际传递与采样

滤波器、光学传递与整数采样各有自己的定义域和适用条件。

  1. 同频同向振动的相量合成用复振幅保留振幅和相位，逐步求出同频振动的合成结果。
  2. RC 滤波：频率响应、相位与负载从电容电流推导传递函数，完整计算单频响应并检查近似条件。
  3. 惠更斯—菲涅耳原理与标量衍射从复振幅叠加进入衍射积分，明确标量近似的适用条件。
  4. 圆孔衍射、Airy 斑与数值孔径从圆孔傅里叶积分得到衍射极限，区分判据与绝对界限。
  5. 傅里叶光学：空间频率与成像传递从衍射核导出空间频谱，并分别推导相干场和非相干强度传递。
  6. 离散序列的周期、混叠与单位根整数采样后先按模 2π 合并频率，再用单位根的阶求整数周期。

能量、稳定与平衡涨落

区分守恒量、稳定性、耗散与统计响应，逐一核对它们的假设。

01由能量控制运动

正定能量可控制位移；半正定情形要单独检查零模态。

  1. 耦合振动、质量内积与简正模式从二次能量构造模态基底，并由初值求各模式的激发。
  2. 正定能量与平衡稳定性区分守恒、Lyapunov 稳定、渐近稳定与零模漂移。

02宏观响应的统计来源

固定系综后计算均值和方差，明确宏观极限成立的条件。

  1. 正则系综与配分函数由热库导出玻尔兹曼权重，再计算宏观响应。
  2. 巨正则系综、巨势与粒子数涨落在热交换之外允许系统交换粒子。
  3. 热涨落：系综、响应与宏观极限完整推导能量和粒子数方差，解释宏观确定性的相关性前提。

03协方差与静态柔度

对配分函数求导推导响应矩阵，区分静态关系与动态耗散。

  1. 静态涨落—响应关系与协方差矩阵由正则分布直接微分，连接柔度、热涨落与稳定性。

从猜想到证明

由候选发现出发，学习反例、双向验证、对称消去、构造与最优界。

01候选、反例与等价验证

用试探发现候选，用不变区间或双向推导覆盖全部情况。

  1. 猜想、反例与候选集合以解集包含关系区分发现、排除、必要条件与充分验证。
  2. 幂迭代的归一化与稳定区间用可逆仿射换元求出精确通项，并从模长区分收敛、固定点与发散。
  3. 双曲线弦中点、共轭方向与调和分点双曲线弦的中点与方向相互共轭，切点弦是极线，极点在弦上给出调和分点。

02几何不变量与定点轨迹

保留分支与定义域，再把构型转成可验证的坐标关系。

  1. 直线族过定点的系数判据先求候选交点，再验证整族直线的系数恒等式，并检查退化成员。
  2. 定点反演与距离乘积把同射线上的距离乘积转成可逆坐标映射，并证明圆与直线的变换关系。
  3. 椭圆焦点弦及其倒数恒等式用焦点极坐标统一焦点弦长度、垂直弦倒数和复合弦构型。

03对称、计数与正交分解

分清哪些量随操作保持，哪些自由度仍然存在。

  1. 有限期望的线性性与指示变量把出现的对象总数写成指示变量之和，避免枚举整个联合分布。
  2. 有限均值的对称配对与删点公式用保持权重的配对消去总和，再计算删除对象后的均值。
  3. 二面角的正交截面与距离分解把沿棱的高度差和垂直于棱的平面几何分开，避免用空间角代替二面角。

04必要条件与构造存在

先证明任何解必须满足的约束，再给出达到约束的合法对象。

  1. 等间隔部分和与连续分组先把部分和条件差分成块和，再处理局部等比数列与分组边界的对齐。
  2. 圆的截弦与等宽条带把同时截多个圆的问题化为圆心投影的区间交，再由垂距计算弦长。
  3. 同余与一次同余方程同余类运算、逆元条件、非互素系数的正确约分和全部解类。

05统一界与等号条件

区分一个参数下的极值和所有参数中最好的极值。

  1. 含参最优界与极小极大先给每个参数一个不可突破的界，再构造一个在全定义域达到该界的参数。
  2. 切线、高阶余项与不等式放缩用凸凹性与有符号余项建立指、对、三角函数界，并通过等号位置判断串联后是否严格。
