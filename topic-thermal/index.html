热学状态与实验基础

  1. 热力学系统、平衡态与状态空间区分系统边界、平衡约束和过程路径。
  2. 第零定律、温度与温标从热平衡的传递性建立温度概念。
  3. 热容、量热与潜热按物态和约束分段进行能量核算。
  4. 热膨胀、压缩性与约束应力把材料响应写成带约束的偏导数。
  5. 理想气体状态方程与经验气体定律统一物质的量、数密度与状态变量。
  6. 分压、摩尔分数与混合气体区分粒子计数、质量分数与摩尔分数。
  7. 分子相互作用、维里展开与实际气体从稀薄极限区分排斥体积和吸引作用。

气体动理论与微观运动

  1. 压强、温度与分子动量通量由撞壁冲量推导理想气体压强。
  2. 麦克斯韦速度分布与三种特征速率区分速度密度、速率密度与通量加权。
  3. 能量均分定理与适用条件每个独立二次能量项贡献二分之一热能。
  4. 分子自由度、转动振动与热容按结构和温度判断哪些模式被激发。
  5. 平均自由程、碰撞频率与稀薄气体输运从碰撞截面辨别微观与宏观尺度。
  6. 玻尔兹曼因子与重力场中的气体连接静力平衡与粒子势能分布。
  7. 分子逸出、撞壁通量与格雷厄姆定律说明穿孔粒子的速率为何高于总体平均。
  8. 布朗运动、随机游走与爱因斯坦关系从涨落与阻力的一致性理解扩散。

第一定律与热力学过程

  1. 热力学第一定律、内能与过程功统一以吸热和外界对系统做功为正。
  2. 等容、等压、等温与路径依赖逐段确定功、内能变化与热量。
  3. 绝热、等熵与泊松关系区分不传热与不产生熵。
  4. 多方过程与过程热容用一族路径统一理想气体过程。
  5. 焓、定压热容与迈耶关系解释恒压传热为何自然对应焓。
  6. 控制体能量、流动焓与稳流装置区分物质携带能量和边界传热做功。
  7. 自由膨胀、节流与焦耳—汤姆孙效应分别识别定内能和定焓的降压过程。

第二定律、熵与循环

  1. 第二定律、可逆性与过程方向把系统和环境能否同时复原作为可逆性的判据。
  2. 卡诺定理、绝对温标与制冷极限从可逆循环得到与工质无关的效率界。
  3. 热机、制冷、回热与常用理想循环逐段核算吸热与排热，避免以净热量作效率分母。
  4. 克劳修斯不等式与熵的定义用可逆路径定义状态函数，用熵产生描述不可逆性。
  5. 理想气体、量热、相变与混合的熵变把不可逆过程的端点连接到可积分的平衡路径。
  6. 最大有用功、可用能与熵产生损失在给定环境条件下衡量能量的做功能力。
  7. 第三定律、绝对熵与低温极限说明熵的参考点和量热积分的条件。

热力学势与物质交换

  1. 基本热力学关系与自然变量把能量、熵、体积与组成纳入同一状态函数。
  2. 焓、亥姆霍兹自由能与吉布斯自由能按环境控制量选择正确的平衡判据。
  3. 麦克斯韦关系与热力学偏导数用混合偏导的对称性连接可测响应。
  4. 热容差、膨胀系数与绝热压缩性推导一般物质的热响应恒等式。
  5. 热稳定性、凸性与相分离判据区分驻点、局部稳定、亚稳和全局平衡。
  6. 化学势、物质迁移与扩散平衡以受约束的自由能变化定义物质转移的驱动力。
  7. 广延性、欧拉关系与吉布斯—杜亥姆方程说明同一混合物的化学势不能任意独立改变。

相变、界面与临界现象

  1. 相、相平衡、相图与吉布斯相律按独立组分和共存相数计算状态自由度。
  2. 克拉珀龙方程、潜热与饱和蒸气压由化学势相等推导相界斜率。
  3. 范德瓦耳斯临界点与麦克斯韦等面积构造用稳定性和化学势替换不物理的等温回环。
  4. 表面自由能、表面熵与拉普拉斯压差从界面面积功连接力学和热力学。
  5. 接触角、润湿与毛细上升用三种界面自由能确定接触线条件。
  6. 开尔文效应、成核势垒与亚稳态解释曲率和界面代价如何延缓相变。
  7. 蒸发、沸腾、饱和蒸气与湿度区分平衡蒸气压、总压与相变速率。

化学热力学的物理基础

  1. 偏摩尔量与混合物的广延性质在固定温压下量化增加某组分的边际效应。
  2. 理想混合熵与吉布斯佯谬从体积可达性与粒子不可分辨性理解混合。
  3. 标准态、活度、活度系数与逸度让化学势公式同时适用于理想与非理想体系。
  4. 理想溶液、拉乌尔定律与亨利定律由液汽化学势匹配得到蒸气压规律。
  5. 渗透压、沸点升高与凝固点降低以溶剂化学势下降统一依数性。
  6. 二元相图、共同切线与杠杆规则从自由能曲线求共存组成和相比例。
  7. 反应内能、反应焓与赫斯定律建立化学能与量热实验之间的一致记账。
  8. 反应进度、亲和势与化学平衡常数由受约束的自由能极小推导质量作用定律。
  9. 吉布斯—亥姆霍兹关系与范特霍夫方程定量分析温度和压力如何影响平衡。
  10. 电化学势、能斯特关系与电池功把带电物质迁移和电功纳入热力学。

统计基础与量子热现象

  1. 微观态、微正则系综与统计熵从可达状态计数得到温度和热平衡。
  2. 正则系综与配分函数由热库导出玻尔兹曼权重，再计算宏观响应。
  3. 巨正则系综、巨势与粒子数涨落在热交换之外允许系统交换粒子。
  4. 理想气体配分函数与萨克尔—特特罗德熵把状态方程、化学势和粒子不可分辨性连在一起。
  5. 爱因斯坦固体、德拜模型与低温热容用量子模式占据修正经典均分。
  6. 热辐射、普朗克分布与黑体定律从光子模式得到辐射能量和传热规律。
  7. 玻色、费米与经典极限从单态占据限制得到量子分布。
  8. 热涨落：系综、响应与宏观极限完整推导能量和粒子数方差，解释宏观确定性的相关性前提。
  9. 静态涨落—响应关系与协方差矩阵由正则分布直接微分，连接柔度、热涨落与稳定性。

传热、扩散与非平衡基础

  1. 傅里叶导热、热阻与稳态传热由局部温度梯度计算热流。
  2. 热扩散方程、边界条件与弛豫时间从局部能量守恒导出温度演化。
  3. 牛顿冷却与集中热容模型从能量收支推导指数冷却，并说明物体内部何时可以视为等温。
  4. 干绝热递减率与大气稳定性比较小气团与环境的温度变化，推导干对流的局部稳定判据。
  5. 菲克定律、扩散方程与化学势梯度从守恒和驱动力理解物质输运。
  6. 局部熵平衡、不可逆输运与昂萨格关系把导热、扩散和反应写成流与驱动力。
