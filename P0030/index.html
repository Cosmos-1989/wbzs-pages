一维光子晶体的反射主极大与缺级

从界面连续条件出发叠加弱反射振幅，分析布拉格主极大、缺级及其邻域。

15P薄膜干涉光子晶体等比求和近似展开
难度与预备知识

需一致追踪多界面复振幅相位，并区别主极大、结构消光及有限层数带来的峰位修正。

预备知识：波的边界连续条件、复数与等比求和、泰勒展开。

1.1 物理情境

光在折射率均匀的介质中沿直线传播；当折射率沿传播方向周期变化时，不同界面的反射波发生相干叠加，某些频率形成显著反射。

3 方法与讨论

一阶反差展开首先是固定 NNN 下关于 δn\delta nδn 的展开。若令 NNN 同时很大，主峰处的振幅约为 2N∣r0sin⁡(kn2d2)∣2N|r_0\sin(kn_2d_2)|2N∣r0​sin(kn2​d2​)∣；当它不再远小于 111 时，多次反射不可忽略，一阶公式可能错误地给出大于 111 的反射振幅。一个方便的充分控制条件是 N∣r0∣≪1N|r_0|\ll1N∣r0​∣≪1。较强反射应使用完整的传输矩阵。

有限 NNN 时，kD=mπkD=m\pikD=mπ 是周期干涉因子的精确最大点，乘上随频率变化的单周期包络后，总反射峰的位置一般有微小偏移。本题给出的 ωm\omega_mωm​ 是 N≫1N\gg1N≫1 时主峰位置的领先阶，不能把它当作任意有限 NNN 的精确极值公式。

更具体地，记 x=kDx=kDx=kD、α=n2d2/D\alpha=n_2d_2/Dα=n2​d2​/D。远离缺级且包络平滑时，总振幅极值满足

（14）

在 x=mπ+ηx=m\pi+\etax=mπ+η 附近展开，得到 η≃3αcot⁡(αmπ)/(N2−1)\eta\simeq3\alpha\cot(\alpha m\pi)/(N^2-1)η≃3αcot(αmπ)/(N2−1)，为 N−2N^{-2}N−2 量级修正。缺级时包络为零，该局部展开不适用，须采用前述缺级展开。
