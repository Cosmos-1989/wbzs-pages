3 方法与讨论

3.1 一个局部模型引出三种全局问题

统一模型 (−1)nu(1−u)n(-1)^n u(1-u)^n(−1)nu(1−u)n 把符号、零点和段内极值分离。整数零点与非整数极值点是两列不同的有序点，必须分别计数；函数的正峰值则控制 C 中的全区间上界。

3.2 开区间计数的边界机制

计数只会在窗口端点越过某个零点或极值点时变化。先写“左邻点在外、目标点在内、右邻点在外”的不等式，再求参数交集，可以避免凭图估计所造成的端点错误。

3.3 从峰值理解衰减

在固定 u∈(0,1)u\in(0,1)u∈(0,1) 时，u(1−u)nu(1-u)^nu(1−u)n 随 nnn 指数下降；但取最大值时，峰的位置 u=1n+1u=\frac{1}{n+1}u=n+11​ 向左端移动，最大值只有 1n\frac{1}{n}n1​ 的量级。这揭示了“固定位置比较”与“对位置取上确界”的不同。上述结构可解释四个选项如何共同构成一道题；这是由函数性质作出的命题分析。
